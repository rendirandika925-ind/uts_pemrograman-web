## Daftar Fitur

1. **Struktur Semantik HTML5** pada 4 halaman (`index.html`, `tentang.html`, `katalog.html`, `kontak.html`).
2. **Tabel Jam Operasional** menggunakan tag `<table>`, `<thead>`, dan `<tbody>`.
3. **Formulir Kontak Validasi HTML5** (`required`, `type="email"`, `pattern`, `minlength`, `maxlength`).
4. **Layout Responsif CSS** menggunakan Flexbox (navigasi), CSS Grid (katalog), variabel `:root`, animasi `@keyframes`, serta 2 media query (`<= 600px` dan `>= 992px`).
5. **Fitur Bonus JavaScript**: Toggle menu hamburger mobile, validasi form kustom, dan filter/pencarian katalog berbasis array objek.
